INTRODUÇÃO

Este documento tem como objetivo auxiliar os profissionais da Prefeitura do Recife no uso do sistema CADSUS WEB. O CADSUS WEB é uma plataforma destinada ao gerenciamento e integração de informações de saúde, proporcionando uma maneira eficiente de registrar e acessar dados dos cidadãos e das unidades de saúde. Por meio deste sistema, os profissionais podem realizar diversos processos administrativos e operacionais, contribuindo para a melhoria da gestão e dos serviços prestados à população. Este guia foi desenvolvido para fornecer instruções claras e detalhadas, garantindo o correto manuseio e utilização eficaz do sistema, assegurando que todas as funcionalidades sejam aproveitadas de maneira otimizada.

Antes de cadastrar um novo registro, é obrigatório realizar uma consulta para verificar se o cadastro do cidadão já existe. Para mais detalhes de como fazer uma consulta, consulte o documento DSS-002.

Caso o registro não esteja na base de dados, aparecerá uma mensagem (pop-up) perguntando: “Este usuário não foi encontrado na base de dados! Deseja cadastra-lo?”

Confirme que deseja iniciar um cadastro: Clique no botão "Sim" para iniciar o cadastro.

4.5.1 Todos os campos obrigatórios têm uma faixa no canto lateral esquerdo vermelho.

Importante: O sistema não permitirá salvar o cadastro se esses campos não estiverem preenchidos.

4.9.1 Passe o cursor do mouse sobre o título de cada campo para exibir as dicas de preenchimento.

4.9.2 Outra opção é clicar no título do campo, exibirá um pop-up com explicação detalhada sobre como preenchê-lo.

Os campos Mãe e Pai tem opções especiais:

Campo "Mãe": Pode ficar em branco se você marcar a opção "Desconhecida".

Campo "Pai": Também pode ser marcado como "Desconhecido" se o cidadão solicitar.

O cadastro é dividido em quatro partes:

Dados Pessoais: Informações básicas como nome, data de nascimento, etc.

Contatos: Telefone, e-mail, endereço, entre outros.

Documentos: RG, CPF, e outros documentos oficiais.

Dados Biométricos: Impressões digitais, foto, ou outros dados biométricos.
