05 Processo 001 — Instalação do Banco de Dados

Descrição: Instalação do banco de dados – servidor sistema LOCUS.

PASSO A PASSO Configuração e instalação do PostgreSQL 9.4 ▾
Configuração da máquina servidor: Firewall desativado, Conexão Remota habilitada, TeamViewer instalado
Usuário ADM padrão: GGTI · Senha padrão: m@ch!n3
IP Fixo na máquina; configuração de impressora com DOSPrint; máquina servidor configurada para nunca hibernar
Baixar instalador do PostgreSQL 9.4: postgresql.org/download
Instalar PostgreSQL 9.4 clicando em Next até a solicitação de senha; inserir a senha do banco central e continuar até o Finish
Desmarcar a opção Stack Builder e clicar em Finish
Abrir o PGAdmin, conectar ao servidor PostgreSQL com a senha definida na instalação
Criar banco de dados com nome locus; clicar com botão direito em locus → Restore; selecionar arquivo de backup; em rolename escolher postgres
Resultado esperado: nenhum erro, code 0; clicar em Done
Acessar C:\Program Files\PostgreSQL\9.4\data, abrir pg_hba com bloco de notas; alterar IP padrão 127.0.0.1/32 md5 para 10.0.0.0/0 password; salvar
06 Processo 002 — Instalação da Aplicação

Descrição: Instalação da aplicação do sistema LOCUS.

PASSO A PASSO Configuração do locus.jar ▾
Ir na pasta com os arquivos Locus
Clicar com botão direito no executável LOCUS exe.jar → Abrir com → WinRAR archiver
Selecionar o arquivo LOCUS.properties → botão direito → Abrir com → Bloco de Notas
Inserir o endereço IP da máquina servidor do sistema LOCUS (se for a máquina-servidor, usar o IP da própria máquina)
Salvar a alteração do IP e clicar em Sim para confirmar a modificação do arquivo
✅ Aplicação Configurada!

08 Processo 004 — Ativar / Desativar Usuário

Clicar na aba Operador

Para ativar: clicar no quadrado Ativo
Para desativar: desmarcar o quadrado Ativo
09 Processo 005 — Incrementar / Corrigir Sistema Indisponível

Descrição: Procedimento para corrigir sistema indisponível.

ERRO 1 Erro de conexão IP ▾
Verificar se o endereço IP do servidor e da aplicação são os mesmos
Verificar se o Firewall do Windows no servidor está ativado — se estiver, desativá-lo
Verificar o arquivo PG_HBA na pasta postgresql da unidade C: e configurar se necessário
ERRO 2 Não imprime — DOSPrint ▾
Colocar o Dosprint.exe na pasta Inicializar
Se funcionar, colocar o arquivo dosprint.bat (renomear dosprint.txt para dosprint.bat)
Abrir o dosprint.bat e trocar o caminho da pasta onde está o executável. Ex: cd \LOCUS
Botão direito no ícone do DOSPrint → Configure → selecionar porta LPT1 ou USB → clicar em Set → selecionar impressora Fx890
ERRO 3 Erro nas rotinas de backup ▾

Pode ocorrer por 3 motivos:

a) Máquina servidor local da unidade parou de funcionar → problema de hardware
b) Máquina com as rotinas de backup parou de funcionar → problema de hardware
c) Endereço IP da máquina servidor foi alterado → acessar 192.168.131.118 → Pasta arquivos bat backup locus → escolher unidade com erro → botão direito → Editar → corrigir IP → salvar
